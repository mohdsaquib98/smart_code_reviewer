## 🤖 Smart Code Reviewer

🔗 **Live App:** https://smartcodereviewer-hjasuydf7kjnzuahhfyjs9.streamlit.app/
🔗 **GitHub Repo:** https://github.com/mohdsaquib98/smart_code_reviewer

---

### What it does:

* Reviews code snippets with AI-powered analysis
* Checks for:

  * Security vulnerabilities
  * Performance issues
  * Error handling gaps
  * Code quality and maintainability
* Customizable via a simple `smart_code_reviewer_prompt.md` file to match your coding standards
* Provides structured feedback with severity levels:

  * Critical / Important / Medium

---

### How developers use it:

* Paste code into the app and select language
* Run AI analysis instantly
* Optionally customize rules using the `.md` prompt file
* Use feedback before submitting code for review

---

### Best for:

* Catching security issues early (SQL injection, XSS, credential exposure)
* Improving code quality before PR submission
* Getting instant feedback without waiting for reviewers
* Ensuring consistent coding standards
* Reviewing AI-generated code (ChatGPT, Windsurf, Devin)

---

### Not for:

* Business logic validation
* Architecture decisions
* Replacing human code review (it complements it)

---

### Key differentiator:

**Fast, customizable, and consistent.**
Control review behavior using a simple Markdown file and get instant AI feedback anytime.
